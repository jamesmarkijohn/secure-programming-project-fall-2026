Built by **James Markijohn** and **Samaa Hediya**

To run this web application:

0. Before anything else, ensure that the following dependencies are installed:

Docker with Compose (latest versions)

Node.js (v.24.21.0)

Python 3.14.7

2. Clone or download the repository.

3. Navigate to the root folder for the cloned repository, and run the following command:

`docker compose up -d`
